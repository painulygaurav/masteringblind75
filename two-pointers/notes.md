# About the pattern
- Traversing or manipulating sequential data structures (arrays, linked lists)
- two pointers moving in a coordinated way in the **same** or **different** direction
## Examples:
1. Detecting a palindrome
2. Reversing an array
3. Pair with given sum in a sorted array

## Pattern to look for in the problem
- **Linear data structure:** Array, linked list, or string
- **Process pairs:** Data elements at two different positions simultaneously
- **Dynamic pointer movement:** Movements of the points are independent
